# program-pengelolahan-nilai
program juga menentukan predikat rata-rata kelas berdasarkan rata-rata nilai yang didapat. Output program menampilkan daftar nilai siswa beserta predikat, rata-rata kelas, dan predikat kelas. Dengan adanya program ini, guru dapat mengolah nilai siswa secara lebih cepat, lebih rapi, dan mengurangi kesalahan perhitungan dibandingkan cara manual
